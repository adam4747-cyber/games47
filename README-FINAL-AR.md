# gems 47 — الإصدار النهائي

## الملفات

- `gems-47.html`: نسخة متصفح واحدة تعمل محليًا دون إنترنت للطور الفردي ووضع التجربة الجماعي.
- `gems-47-portable.zip`: حزمة المتصفح المحمولة الجاهزة للمشاركة.
- `gems-47-project.zip`: المشروع الكامل القابل للتطوير والنشر، ويشمل واجهة React وخادم tRPC وقاعدة البيانات.

## التشغيل المحلي

افتح ملف `gems-47.html` مباشرة في Chrome أو Edge أو Firefox. لا يحتاج هذا الملف إلى اتصال بالإنترنت للعب الفردي، المتجر، الإنجازات، الجوائز اليومية، المؤثرات، ووضع التجربة الجماعي.

## النشر

للنشر السريع ارفع ملف `gems-47.html` إلى استضافة ملفات ثابتة. ولتفعيل الغرف الأونلاين الحقيقية، انشر المشروع الكامل باستخدام إعدادات Manus وقاعدة البيانات والمصادقة، ثم شغّل `pnpm install` و`pnpm build`.

## الأونلاين

تدعم غرف الأونلاين المؤمّنة بعد تسجيل الدخول: **من سيربح المليون**، **تحدي المنطق**، و**XO**. تدعم الغرف لاعبين أو ثلاثة، وتزامن الأدوار والنتائج عبر الخادم. وضع التجربة المحلي متاح دون تسجيل دخول لاختبار اللعب الجماعي مباشرة.

## التحقق النهائي

تم تشغيل فحص TypeScript، والاختبارات، وبناء الإنتاج بنجاح. كما تم اختبار جولة المليونير، الإجابات الصحيحة والخاطئة، وضع التجربة الجماعي، المتجر، وفلاتر الأصوات والثيمات.
